# Knowledge proposals

Worker suggestions and onboarding progress live here. They are excluded from the index and cannot establish owner preferences or authority.

Name proposals YYYY-MM-DD-topic.md and use the page format in ../README.md with verified: no. Add `target: <folder>/<page>.md` to the header to name the page a proposal creates or replaces. The owner confirms the summary before the page is moved into the knowledge index. Use onboarding-progress.md to record completed topics and unanswered questions when an interview pauses.
