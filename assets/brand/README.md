# Serra brand

Serra is Portuguese for "mountain range." The idea: you hand Serra the climb, it goes over the ridge and comes back with the result.

The mark is a switchback trail that forms an S. The sun at the summit is the bot's status light.

| File | Use |
|---|---|
| `serra-icon.png` | App icon (1024×1024) |
| `serra-lockup.png` | Mark and wordmark, for the README and docs |
| `serra-status-up.png` | Bot is up |
| `serra-status-needs-you.png` | Bot needs the owner |
| `serra-status-down.png` | Bot is down or Slack is disconnected |
